# Руководство пользователя — НормоСкан

## 1. Быстрый старт

1. Войдите: `admin/admin123` (админ), `norm/norm123` (нормоконтролер), `engineer/eng123` (инженер)
2. Загрузите PDF в «Загрузка» → получите `check_id`
3. Отслеживайте в «Проверки» → отчет с ошибками и метаданными
4. У каждой ошибки нажмите 👍/👎 — отрицательные уйдут на дообучение

## 2. Настройка шаблонов метаинформации (JSON-схемы)

По умолчанию схема (ГОСТ 2.104):

```json
{
  "type": "object",
  "properties": {
    "Обозначение": {"type":"string","pattern":"^[A-ZА-Я0-9\\.\\-]+$"},
    "Наименование": {"type":"string"},
    "Материал": {"type":"string"},
    "Масса": {"type":"string"},
    "Литера": {"type":"string","enum":["","О","О1","О2","А","Б"]},
    "Масштаб": {"type":"string"},
    "Формат": {"type":"string","enum":["А0","А1","А2","А3","А4"]}
  },
  "required": ["Обозначение","Наименование"]
}
```

Изменить: `GET /api/checks/meta/schema` — скачать, отредактировать, `POST /api/admin/settings` или через код `backend/app/services/metadata.py`.

Кастомные поля автоматически попадут в `technical_metadata` и в базу знаний (knowledge base).

## 3. Обучение Visual RAG (Галерея)

**Как добавить пример ошибки перетаскиванием:**

1. Перейдите «Галерея»
2. Перетащите скриншот (PNG/JPG) в поле «Скриншот»
3. Заполните:
   - Название: `Неверная засечка стрелки`
   - Категория: `error` (ошибка) или `etalon` (эталон)
   - Ссылка на ГОСТ: `ГОСТ 2.305`
   - Тип ошибки: `засечка`
4. Нажмите «Добавить в галерею» — эмбеддинг (CLIP/hash) сохранится в Qdrant
5. При анализе нового чертежа система найдёт косинусную близость; если >82% — VLM получит подсказку: «Данный элемент на 92% похож на ошибку типа 'Неверная засечка'».

**Советы:**
- Делайте кроп именно узла (стрелка, допуск), не всего листа
- Добавляйте и эталоны (правильные примеры) для контраста
- Ошибки с 👎 автоматически логируются в `storage/retrain/feedback.log` — раз в неделю просматривайте и добавляйте в галерею

## 4. Вопросы по ГОСТам и документам

- Вкладка «Вопросы» → «Вопрос по ГОСТам»: `Что требует ГОСТ 2.307 по допускам?` — ищет в Text RAG
- «Вопрос по документу»: укажите ID проверки, спросите `Какая масса?` или `Какие ошибки по ГОСТ 2.104?`
- Через MCP: внешние LLM могут вызывать `ask_gost`, `ask_document`

## 5. Аналитика

«Аналитика» → сводка: `В отделе №5 за месяц участились ошибки в оформлении допусков (ГОСТ 2.307)` — формируется из статистики `top_errors`.

## 6. RBAC

- **viewer**: только просмотр
- **engineer**: загрузка своих чертежей, просмотр
- **normocontroller**: + управление галереей, ГОСТами, просмотр аналитики
- **admin**: всё + настройки модели/очереди/пользователей

Интеграция с Koseven: включите `KOSEVEN_ENABLED=true`, укажите `KOSEVEN_DB_DSN`, система будет маппить роли из заголовка `X-Koseven-Role`.

## 7. FAQ

**Q: Поддерживается ли А1 простыня?**  
A: Да, но она режется на зоны 768px. Не подавайте всю простыню целиком — кроппер выделит штамп/техтребования/графику.

**Q: Данные уходят в OpenAI?**  
A: Нет, весь инференс локальный.

**Q: Как увеличить контекст?**  
A: Админка → MAX_CONTEXT_WINDOW до 32768 (требует больше VRAM).
